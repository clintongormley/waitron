## Designs that do not supply a current procedure

- **A940 release preparation and tagging:** section 5.4 proposes `pnpm release prepare` and
  `pnpm release tag`; neither is a current root script at this snapshot. Keep the existing
  [deployment instructions](../../deploy/README.md). The release implementation must deliver
  its own runbook before anyone follows those proposed commands.
- **B3 USB installation, maintenance/support access, A799 real-upgrade rigs, A951 connection,
  A982 problem reports and A664 retention:** proposed or separately gated build/policy work.
  Illustrative maintenance-account commands are not an implemented access procedure.
- **W41s future filing remedies, A696 zone repair, A947 minute selection/failover, A1018 hosted
  writer moves, A739 payment-window and A803 bill/table redesign:** use their delivered current
  predecessors above. This audit supplies no authority to run their future flows.
- **Old custodian-register and dormant-certificate protocols:** retain the historical labels in
  their permanent developer references. Do not use those formats as today's activation path.
- **Campaign account pooling:** external development infrastructure, not a venue procedure.
  Its dated controller cutover and account roster are not copied into product operating docs.
  This audit does not verify the external tools repository's current instructions.
- **Other build plans, test checklists, experiments, mockups and source inventories:** these
  describe implementation work or historical evidence, rather than additional operating steps.

New work can add a procedure after this pin. Before the go-live deletion, repeat the sweep and
retain any newly delivered steps. Nothing here deletes planning files, begins A760's freeze or
changes the current production migration rule.
