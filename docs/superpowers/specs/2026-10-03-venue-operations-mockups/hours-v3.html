Hours v3: special dates as rows, shown on a calendar

The standard week grid is unchanged. A special date is still a row (option A), now with a name and a colour, a Duplicate action, and a month calendar view of the same rows. There is no day-type setup step: the colour belongs to the row.

Duplicate asks only for the new date (or several dates), and copies the name, the colour and every cell. Above, Todos los Santos was duplicated from Fiesta Nacional and renamed. Editing a row is the same form as adding one:

Colour: : a fixed set of the theme's colours, so each reads in light and dark mode. The two fixed colours (standard and closed) are not in the set, so a special date never looks like either. "Close the whole venue on a date" makes a row in the Closed colour; any date where every department is shut shows as Closed.
