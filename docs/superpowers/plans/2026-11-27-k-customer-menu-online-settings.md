# Customer menu Online settings

A manager can save whether a menu should be online, its address segment and photo size from **Customer menu**. The preview still shows published dishes and reflects the draft photo choice. Settings take effect on Save. This slice says why customers cannot open the menu yet. Public hosting, usable addresses, sharing buttons and the list's Online column wait for Delivery 6. Styles, Print and fonts follow their own deliveries. [Customer menu design, Delivery 3](../specs/2026-11-24-customer-menu-design.md#delivery)

## Save settings

- Add `CustomerMenuOnlineSettings` with `enabled`, nullable `address` and `photos` (`none`, `small`, `large`) in `packages/shared/src/menu-document/customer-menu-presentation.ts`. Map Large to the current preview. In `packages/db/src/schema/menus.ts`, default to Off and no address. Add a unique address index for active regular menus, including ones switched off. Omit Online and address from configuration transfer in `packages/db/src/configuration-transfer.ts`; keep photos. Rebuild the core baseline with `pnpm --filter @waitron/server migration-baseline rebuild --set core`. The change requires a venue reset.
- Add `readCustomerMenuOnlineSettings` and `saveCustomerMenuOnlineSettings` in `packages/menu/src/customer-menu-online-settings.ts`. Use `assertMenuWritable`, `refuseSetMenu` and `liveVersions` in the same transaction. Enabled requires a live publication and an address made of lowercase ASCII letters, digits and hyphens. Validate a supplied address even while Off. Map a taken address and invalid address to the address field. A new or duplicated menu starts Off without an address.
- Mount GET and PUT `/management-api/menus/:id/customer-online-settings` through `apps/server/src/menu-customer-online-settings-routes.ts` and the existing `gated` transaction in `menu-api.ts`. Read and save return the settings. Validate the request shape in the route. Keep the preview read separate.
- Start with failing `packages/menu/src/customer-menu-online-settings.test.ts` cases for defaults, save independent of publishing, unpublished enabling, duplicate address and leaving settings intact on refusal. Add mounted-route cases in `apps/server/src/menu-api.customer-online-settings.test.ts` for permission, menu kind, malformed input and the saved response. Round-trip an enabled source with Small photos in `packages/menu/src/configuration-transfer.test.ts` and assert Off, empty address and Small on import.
