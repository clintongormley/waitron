# Shared table controls implementation plan

**Outcome.** Staff can sort from anywhere in a sortable heading and tick from anywhere in a checkbox cell, including select-all. Help and drag handles keep their own targets. Developers can opt into one dense-row setting for the later Products and menu editor changes. This is PRODUCTS-LIST-1, piece 1 (§2, §7.2 and Delivery) of the [Products list design](../specs/2026-11-24-products-list-redesign-design.md). One pull request, with the default density, storage and dependencies as they are.

## Whole-cell targets

- [ ] **Red.** In `packages/ui/src/components/wt-data-table.head-and-cells.test.ts`, add “sorts from blank heading space once” and “ticks from blank selection space once”. Use real Chromium pointer coordinates. Before the click, inspect the actual hit at a point outside the visible control so a covered cell fails with a clear assertion. Test a sortable tree heading in its indented margin, a pinned sortable heading after both scrolls, and one event for pointer or keyboard activation with `aria-sort` on the active column alone. For selection, cover select-all going from mixed to checked, Space on the checkbox, and blank cell space in flat and tree rows that open, expand or do neither. A cell with only a grip keeps its existing row action. In `wt-data-table.help.test.ts` beside that suite, click the badge, its open bubble and blank space on that same heading. Only the blank space sorts.
- [ ] **Red.** In `apps/dashboard/src/widgets/product-list.test.ts`, press empty selection space and move past the drag threshold. Assert no drag starts, then show the grip still starts it. In `apps/dashboard/src/widgets/menu-structure-table.test.ts`, click padding beside the real grip and check it ticks once, then use the grip and check selection stays put.
- [ ] **Green.** In `packages/ui/src/components/wt-data-table.ts`, forward clicks from blank space to the existing sort button or checkbox, using a small helper in `wt-data-table-cell-controls.ts`. Focus the native control on a forwarded click. Its existing handler owns the change. Skip events from the native controls, supplied controls and the help badge, including its popup. Keep the heading's help anchor, `part="tree-heading"` and sticky layers. Mark only body cells drawing a checkbox with `data-selection-cell`. In the sibling file's styles, raise those cells above the row activator. In `apps/dashboard/src/widgets/product-list.ts`, ignore that marker when starting a drag unless the pointer hit the actual grip.

## Dense rows

- [ ] **Red.** In the head-and-cells suite, add “changes only opted-in body padding at the table's own width”. Compare narrow and wide flat and tree tables with a real tap-height control and wrapping text. Override spacing tokens and check computed padding and row height. Check that turning density off clears the narrow state on a flat table and reattaching it restores the right density.
- [ ] **Green.** Add a reflected `denseRows` / `dense-rows` Boolean, default off. Reuse the table's scroll-width observer and 440 px breakpoint for opted-in flat tables. In the sibling styles, use half `--wt-space-1` per side on wide bodies and half `--wt-space-2` on narrow bodies. Measure near 48/52 px with a 44 px control and let wrapped rows grow. Keep header, inline padding and default width handling.
