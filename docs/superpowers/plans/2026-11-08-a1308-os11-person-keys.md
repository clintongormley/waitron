# A1308 orders and sales, PR 11: person keys on the tables this area keeps — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every column of this area's unchanged tables that names a person a foreign key to
`persons`, and fix the test fixtures that invent person ids.

**Architecture:** Schema-only change plus fixtures. No product code changes unless the measurement in
Task 1 finds a product writer that stores something other than a person's id (a stop).

**Tech stack:** TypeScript, Drizzle ORM on `node:sqlite`, Vitest.

**Spec:** README §5 U11 ("Person ids … every column naming a person gets a key to `persons` … until a row
can be deleted, the key refuses deletion. Test fixtures that invent person ids create a person first");
rules §4; backlog bundle "Person-id columns and `order_draft_lines.menu_item_id` have no foreign key"
(`docs/backlog/architecture.md`, "Small checks …"). Rules: [slice rules](2026-11-08-a1308-slice-rules.md).

**Who lands:** the lane. `sales`, `sale_voids` and `unpaid_departures` got their keys in os8, which the
owner lands; nothing here touches a fiscal table.

**First line of the PR description:** "Every venue is reset: core; backups and exports from before
this cannot be restored or imported."

## Stop points (beyond rules §5)

- A **product** writer stores a value in one of these columns that is not a person's id (for example a
  kitchen display's or the system's id where a source writes no person). Read `order_amendments`'
  `captured_by_source` values (`order-amendments.ts`, `originChecks`): a `kitchen_timer` or
  `payment_check` amendment must still carry a real person, or this is a stop.

3. **Deleting a person who submitted a group** is refused. Test: Task 2.
4. **A transfer request not yet resolved** has `resolved_by` null. Test: Task 2.
5. **The attendance read** joins these tables by person; a key changes no read.
