# Printer Discovery Freshness Implementation Plan

Use the shared steady clock for the time the server treats a printer report as fresh, including listing, Pair, Forget and A4 registration. An in-memory report should age by elapsed time even while the box's date changes. This implements the discovery row in the [owner's steady-clock request](../../backlog/box.md#one-steady-clock-helper-instead-of-hand-written-clock-step-back-guards), assigned to Lane H by the watcher on 22 November at 07:02. The dashboard's address probe and last-seen display still consume calendar dates.

- [ ] Start with failing cases in `apps/server/src/print-api.test.ts`. In “drops a reported device once its last report is older than fifteen seconds”, pin the steady clock before the USB report, step the wall clock by a day in both directions and expect the row and its original ISO `lastSeenAt`. Hold the wall clock and advance steady time to 15,000 and 15,001 ms to pin expiry. For A4 registration, report a printable raw entry and an IPP-only entry for the same queue from one agent. Step the wall clock back a day and advance steady time by a second. Report only one of the two entries again, now unprintable. POST that queue without a discovery-list read in between. Expect `page_printer.not_printable`. The old code picks the earlier report by wall date and answers `page_printer.not_found`. Preserve the same-pull printable preference.
- [ ] In `print-api.ts`, sample `steadyNow()` once per agent pull for the in-memory stamps. Name an entry's steady receipt time `reportedAt` and keep epoch `lastSeenAt` for the dashboard. Move scan, paired, visible and agent Bluetooth capability ages to the steady clock. Keep the 15-second visibility and 60-second capability cutoffs, expiry timer and change events. Exclude `reportedAt` from the inventory change comparison. Use the existing steady discovery deadline for listing, Pair, Forget and the receipt-versus-office address check. Keep the existing response fields for the dashboard's calendar deadline and the agent's rounded duration.
- [ ] In `discovery-listing.ts`, remove the backward-step guard and compare elapsed milliseconds in `withinTtl(at, now, ttl)`. Keep inclusive 15-second closed and 45-second open cutoffs in `isListed(at, now, discoveryEnd)`. Pass the steady `reportedAt` and `{ now, discoveryEnd }` through the existing `PagePrinterDiscovery` and `DiscoveryWindow` interfaces in `page-printers.ts` and their caller in `page-printers-api.ts`. In `print-api.ts`, pick the newest matching queue by `reportedAt`. Update the clock descriptions and the direct registration fixtures in `page-printers.test.ts`, `configuration-transfer.test.ts`, `invoice-page-print.test.ts` and `page-print-api.test.ts`.
- [ ] Replace the future-wall-date cases in `discovery-listing.test.ts` with absent-report and elapsed boundary assertions, including at window closure. Audit `print-api.test.ts` for wall-only age mocks, including the capability list and refresh, Pair and Forget, visibility, independent office queues and typed-in address. For expiry, advance steady time. For clock-step cases, advance wall time independently and expect the printer to stay visible. Advance steady time far enough for the slow-scan renewal case to reach the original window's end. Run the changed server test files and Lane H's queue gates.
