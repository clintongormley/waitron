**Placement and reuse.** Source has Settings → Box status, a health page, not a This box page (`apps/dashboard/src/dashboard-app.ts:284`, `docs/developers/design-system.md:6308`). Mount with `{ passive: true }`; let the controller release the observation on disconnect. No new lifecycle layer or timer.

**Display decisions.** One Network group using `wt-card`, `baseStyles`, declared tokens and a help-mode `wt-help-tooltip`. Show wired connected/disconnected and address, current Wi-Fi, and the saved Wi-Fi name when reported. Connection is not proof of internet access. A connected cable with null address says the address is not reported. Null current Wi-Fi means “Not connected”; null saved Wi-Fi means “Not reported”, never “no adapter” or “nothing saved”: the wire has no radio-presence field and the host can find multiple profiles (`apps/server/src/box-host-client.ts:246`, `scripts/box/network-host.mjs:123`). Decode printable UTF-8 SSIDs as text; otherwise show labelled hex, retaining exact bytes and rendering through Lit text interpolation. Show loading before any answer. On failure hide the previous observation, distinguish unavailable installation from failed read, and say the page checks again automatically; successful recovery clears that message. Keep session refusals in the existing shell flow.
