# A1308 orders and sales, PR 7: one table for a draft's lines — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fold `order_draft_recalled_lines` (a sent dish recalled into a waiter's draft for change)
into `order_draft_lines`, so a draft has one list of lines, each either a new dish or a recalled one,
and give `order_draft_lines.menu_item_id` its foreign key.

**Architecture:** `order_draft_lines` gains `source_line_id` (key to `working_order_lines`, on delete
cascade, partially unique); `menu_item_id`, `options`, `extras` and `quantity` become nullable, and
one CHECK says which kind a row is. Every query that read one of the two tables filters by kind; every
query that read both reads one. The rows already share `position`, `slot`, `join_group_id`,
`after_group_id` and the three slot CHECKs.

**Tech stack:** TypeScript, Drizzle ORM on `node:sqlite`, Vitest.

**Spec:** [tables-ordersales.md](../specs/2026-11-02-rationalisation/tables-ordersales.md) §1.7, §4
(`order_draft_recalled_lines` → merge), §5 (order_draft_recalled_lines); backlog bundle "Person-id
columns and `order_draft_lines.menu_item_id` have no foreign key"
(`docs/backlog/architecture.md`, "Small checks …"). Rules: [slice rules](2026-11-08-a1308-slice-rules.md).

**Who lands:** the lane (nothing fiscal).

**First line of the PR description:** "Every venue is reset: core; backups and exports from before
this cannot be restored or imported."

## What it builds

1. `order_draft_lines.source_line_id` (null, key to `working_order_lines` on delete cascade, as
   `order_draft_recalled_lines_source_fk`); partial unique index `order_draft_lines_source_uq` on
   `(source_line_id) where source_line_id is not null`.
2. `menu_item_id`, `options`, `extras`, `quantity` become nullable; `menu_item_id` gains its key to
   `menu_items` (`packages/db/src/schema/order-drafts.ts:64`, "No key yet").
3. CHECK `order_draft_lines_kind_ck`: exactly one of `menu_item_id`, `source_line_id` is set; a
   new-dish row has `options`, `extras` and `quantity`; a recalled row has no `options`, `extras`,
   `quantity` or `note`. `order_draft_lines_quantity_ck` becomes `quantity is null or quantity > 0`.
4. `order_draft_recalled_lines` deleted; every reader and writer moved.
