# English-only check before push

A developer who pushes general Waitron code sees the English-only guard's path, line, word and fix before upload. The hook checks changed files. CI checks the full tracked tree and list configuration.

- [ ] Add a real-checker case in `scripts/pre-push.test.mjs`. A signed change containing `mesa` must stop the hook and name the path, line, word and fix. Correcting the changed file must pass with the same word in an unchanged file and in a changed translation home. Make the fixture run the real checker only in this case, against the fixture's root. Run the named case first and see the old hook accept the bad push.
- [ ] Put the shared per-file finding and rule evaluation in `packages/db/src/english-only.ts`. Keep the existing `isHome`, text reader, token detection, module vocabulary, and both lists. In `scripts/english-only.test.ts`, preserve the tracked-tree and list checks and the three expectations for clean, kept-count and still-to-clean files. Pin refusals for a kept count one over or under and a still-to-clean file with no findings before moving those checks.
- [ ] Add `scripts/check-english-only.ts`. It takes the repository root and changed paths as arguments. It selects `apps/` and `packages/` files outside translation homes, ignores binary files, and loads the vocabulary from `ALL_MODULES` only when there is text to check. Use the shared rules and report each failure with its actionable fix. For a cleaned still-to-clean file, name the list entry and pinned count to update.
- [ ] After the existing early exits in `.husky/pre-push`, feed the deduplicated regular, non-symlink paths through `check_changed` and `run_step`. Invoke `pnpm --dir apps/server exec tsx ../../scripts/check-english-only.ts` with the hook's root as the first argument. Print the same command with a path placeholder to reproduce a finding. Unknown ranges report that CI will check English and keep the other existing checks. Global scope with known paths still checks those paths. Keep the hook's working-tree content and filename handling. Update the command expectations in `scripts/pre-push.test.mjs` for this one extra step and assert the unknown-range notice.
- [ ] Run `pnpm exec vitest run scripts/pre-push.test.mjs scripts/english-only.test.ts`. Confirm the fixture catches the bad file, accepts its correction, and retains the existing hook limits. Time the checker on a representative push list, aiming for at most five seconds of added work on this Mac, and record the inputs and time in the PR.
- [ ] Update the hook and unknown-range descriptions and source inventory in `docs/developers/ci-and-gates.md`, the source inventory in `docs/developers/testing-guide.md`, `CLAUDE.md` §2 and the A1449 pointer in `docs/backlog.md`.
