## Decisions (with receipts)

1. **What `wt-floor-map` takes per table.** The design says "one state instead of a fill and a
   dot". One state is not enough to draw: Overdue and Waiting draw "its own colour" under their
   outline (§4 rows 2 and 10; pictures 07 and 09 show the calm fill), and the owner's #1918 point 1
   keeps Waiting's outline under a higher state. So the till's ranking (slice 4 Decision 1: it lives
   in the till) is turned into four drawn parts, and `FloorMapTable` carries them: `fill:
   FloorMapFill`, `outline: FloorMapOutline | null`, `pulse: FloorMapPulse | null`, `cue:
   FloorMapCue | null`, plus `description` as today. `dot` goes. Every member of a merge carries the
   same four, as it does `fill` and `dot` today (`wt-floor-map.ts:19`).
2. **The fills** (`FLOOR_MAP_FILLS`): `free`, `reserved`, `seated`, `bill` read their table tokens
   as today; **`calm`** reads the new `--wt-color-table-calm` / `--wt-color-on-table-calm`;
   **`ready`** reads `--wt-color-success` / the new `--wt-color-on-success`; **`danger`** reads
   `--wt-color-danger` / `--wt-color-on-danger`; **`warning`** reads `--wt-color-warning` /
   `--wt-color-on-warning`; **`plain`** reads `--wt-color-surface` / `--wt-color-text`. `clearing`
   is no longer a fill (§4 line 271: "Needs clearing changes from a filled amber table to a dashed
   amber outline"), so `--wt-color-on-table-clearing` is read by nothing and is deleted (Task 7);
   `--wt-color-table-clearing` stays as the dash colour.
3. **Nothing needed's fill (backlog bullet 1)** is a new fill token, `--wt-color-table-calm`:
   light `#e4ecfb`, dark `#22304a` — the values the pictures were drawn with (`gen.mjs`'s `--calm`).
   Its text, `--wt-color-on-table-calm`, is `#16181d` / `#eceef2` (the theme text). The card's left
   edge keeps `--wt-color-table-calm-edge`, a line colour (slice 4b Decision 4). Computed 2026-10-20
   with a node script (WCAG luminance, CIEDE2000 as `colors.test.ts`): text on calm 14.96:1 light,
   11.37:1 dark; calm against free ΔE 13.8 light, 24.3 dark; the field-line border against calm
   3.20:1 and 3.42:1, so the shape's edge still shows on the white or dark map. `--wt-color-on-success`
   is `#ffffff` light, `#06190f` dark: 4.97:1 and 7.99:1 on the success green.

5. **Waiting's cue says "Waiting", not the minutes** picture 07 draws ("⏱ 6′"). The floor read

   `long_wait` signal is `{ kind: "long_wait"; band }` (`packages/shared/src/table-signals.ts`).
   Showing minutes needs a server change, which this slice does not make (Owner point 2). The held
   countdown's minutes do exist (`minutesToFire`, `apps/till/src/state/release-reminder.ts:13`).
6. **An outline on a solid fill gets a 1 px line of the surface colour inside it.** Without it the
   owner's point 1 draws an outline nobody can see: computed 2026-10-20 (same script), red on purple

   so the outline always has the same look. Under `no-hardcoded-chrome` a 1 px width is allowed.
7. **The pulse ring outside the shape.** A span the size of the shape, `border-radius: inherit`,
   `pointer-events: none`, drawn as a 2 px gap of `--wt-color-surface` then a 4 px ring of the
   state's colour: `box-shadow: 0 0 0 calc(var(--wt-space-1) / 2) var(--wt-color-surface), 0 0 0
   calc(var(--wt-space-1) * 1.5) currentColor` — 6 px out against the design's "reaches 7 px", so
   it stays inside the 2-square crop margin at any scale above 3 px a square. Its colour and its dim
   colour come from the existing `.ring-forgotten`/`.ring-overdue`/`.ring-fire` classes and the one
   `wt-pulse` keyframe (`packages/ui/src/floor-ring.ts:22-51`), so it dims to
   `--wt-color-danger-pulse-dim` / `--wt-color-warning-pulse-dim` as the card does. The gap keeps a
   Forgotten table's red ring from merging into its red fill. It paints with its own shape, so a
   table listed later covers it rather than it covering a neighbour's name (the dot was drawn above
   neighbours, `wt-floor-map.ts:343-354`; the ring is wider, and a name matters more). The zone
   tab's ring is the same span (Decision 14).
8. **The cue is drawn only on a table big enough for two lines.** Name and cue sit in one
