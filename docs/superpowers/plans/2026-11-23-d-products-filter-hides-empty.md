# Products filters hide categories with no matches

The owner’s report, the watcher’s search scope and the owner’s “1 of 2 products” answer are recorded under PRODUCTS-FILTER-HIDES-EMPTY in Lane D’s `queue.md`. Codex Lane D wrote this plan for Claude to review and the watcher to clear.

With **Has modifiers**, Coffee, Conserves and Desserts disappear. A match in a subcategory keeps its parent category visible. While a column filter is on, replace each category’s ordinary summary with matching products out of the whole branch’s total. Including subcategories gives a parent credit for the matches that kept it visible. Count each product once even if several variants match. The total counts archived products only while **Show archived** is on, and sets the singular or plural form. Clearing the filters restores the ordinary count and its separate subcategory total. Search still finds a populated category by name and opening it shows the products that pass the column filters. A category with no such products drops out of search, too.

- In `packages/ui/src/components/wt-data-table.ts`, keep the result of the existing conjunction of column filters in the search memo. Give opt-in trees a `filterCandidates` callback to prune that set before name ranking. Use the memo’s narrowed rows in both `#treeShown` and `#flatSearchEntries`, so ordinary filters, search roots and expanded search contents agree. Include the stable callback in the memo’s inputs and skip it if search and filters are empty. Expose the memo’s column-filter matches to the opted-in tree’s cell renderer while a column filter is active, before pruning or ranking, so Products can count matches with the same rules as the table.
- In `apps/dashboard/src/widgets/product-list.ts`, keep the category paths of the surviving product and variant rows, the All products row and the current inline editor. Calculate each path’s filtered and total distinct product counts once per row set. Reuse the table’s saved choices, order and branch state. Localize the filtered count through `apps/dashboard/src/i18n/strings.ts` and retain the narrow layout’s existing visually hidden count. The English and Spanish Products guides explain how to bring back an empty category, including a new category that disappears after you save it while filtering. Document the shared table option in `docs/developers/design-system.md`.
- Chromium measured zero horizontal offset for every measured Actions glyph across Products, Modifiers and Menus at 390 and 1280 px. Record the measurement in the PR. The source for the icons and their layout needs no change.
