# Keep configured server test ports through their first bind

**Finish line.** The remaining Waitron test listeners in the A80 caller audit own their configured addresses up to the real first bind. The tests still use their configured ports, advertised origins and existing refusal and release checks. The scope comes from Lane I's PORT-FIRST-BINDS queue item and [the A80 audit](../../backlog/ci.md#what-the-landing-port-fix-a80-pr-740-left-open).

Use `retainHttpListener` and the existing in-process adoption or Node child transfer. Use the existing ephemeral fixture where the number is incidental. Match the real bind host, install one adoption at a time per process and restore it in failure cleanup. Keep cleanup for the real server first and the holder last when testing server release. Wait for a required adoption before any probe that could consume it or mistake the holder for the real server. Skip the adoption wait for cases where boot should refuse before an expected socket starts.
