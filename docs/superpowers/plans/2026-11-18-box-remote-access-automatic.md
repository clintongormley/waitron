# Automatic remote access on a paired box

**Goal.** After a normal box install or upgrade, pairing with test Cloud makes the assigned staff address open from a phone on mobile data. The **Remote access** switch closes it and brings it back without pairing again. Lane J's BOX-REMOTE-ACCESS-AUTOMATIC queue item records the ask.

**Start and stop behaviour.** Compose starts the existing companion with the box. It prepares its public key and waits. A paired box with remote access on writes `peer.json`, and the companion starts WireGuard and its forwarder. Turning access off removes the file, and the companion tears down both and closes existing connections. The idle companion can then bring the tunnel back.
