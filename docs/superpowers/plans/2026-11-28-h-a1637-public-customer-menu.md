## What Cloud can request

- Connect to the signed route's tunnel IPv4 address on **8443** with the staff name as TLS server name and HTTP Host. The tunnel forwards only the gateway's traffic to `customer-menu.sock` beside `staff.sock`. Admit only a serving test primary with remote access on and a matching certificate and Host.
- Send GET or HEAD. A query on `/`, `/<address>` or `/<address>/<language>` returns 302 to the same path without the query. Asset and photo requests with a query return 404. Any further handling of tracking links belongs to Cloud. `/` lists the online menus, redirects when one is online and returns 404 when none are online. `/<address>` returns 302 with relative `Location: /<address>/<default-language>`. `/<address>/<language>` serves HTML with the embedded snapshot for a stored enabled language tag. Use `https://<Cloud-public-host>/<address>` for pairing. D643 PR 1c must forward relative redirects and their cache headers. The disabled gateway currently accepts only 200 as success. `/<address>/<language>/dish/<id>` remains reserved. Cloud availability and challenge paths keep their existing handling.
- Serve `/_customer-menu/assets/<built-file>` from the release's exact guest asset list, including bundled fonts, and `/_customer-menu/{favicon.ico,favicon.svg,apple-touch-icon.png}`. Photos use `/_customer-menu/photos/v1/<64-lowercase-hex>.<jpg|png|webp>/<square|display>/<x>-<y>-<zoom>.webp`. Small uses square up to 480 × 480, Large uses display up to 1,600 on the longer side, and None lists no photo paths. Serve only listed recipes, within Cloud's 2 MiB reply limit.
- Allow framing. Give pages, redirects and stable icons at most 60 seconds of freshness and content-named assets and photos one year. Missing, switched-off and unlisted paths return 404. Excess work returns 429 and temporary failure returns 503. Serve assets from the installed release. Test a fresh page after restart locally. The paired Cloud rehearsal also checks a cached page across upgrade and takeover before enabling. If it loses an asset, take that result back to the watcher before adding asset retention.
