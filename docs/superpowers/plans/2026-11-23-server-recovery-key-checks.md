# Share recovery-key checks in server tests

A server test file can reuse a recovery-key check for the same secret and stored verifier while tests that watch real derivations still see them. This is the recovery-key part of “Server test time levers left after A1297” in `docs/backlog/ci.md`, assigned to Lane I as `SERVER-TEST-RECOVERY-KEY-REPEATS`.
