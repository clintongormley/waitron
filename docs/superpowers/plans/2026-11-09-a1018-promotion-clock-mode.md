However, **there is no existing browser promotion entry to integrate this mode into: an independently usable clock-mode-only slice is not available on the inspected tree.** Recommend holding implementation until the watcher reconciles “clock first” with delivery through the shared screen. A factory used only by tests would be unused scaffolding; it would not meet this finish line.
