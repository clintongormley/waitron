# Name the prep station in till refusals (A1081)

When a sent-item edit or move is refused, staff see the name of the station that has the work, such as Bar. When the refusal identifies no station, they get a complete sentence without a station name. The owner chose to name the station on 25 October. [Backlog](../../backlog/till.md#settled-small-small-answers-the-owner-gave-that-are-not-built-yet)

An edit save with started work at one station and blocked work at another must report the started station and keep the ticket id. A policy refusal must name the blocking station, including when it is the extra's station. A move to another station reports the source name. Keep the HTTP 409 and original codes. Run those files and confirm the new checks fail for the missing name.
