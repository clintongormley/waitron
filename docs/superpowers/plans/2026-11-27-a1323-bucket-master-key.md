# A1323 PR 5 · Restore from my bucket with the master key

An owner can enter their storage provider’s address, bucket, region, folder and access keys, then use the master key to open a continuous backup. If the folder contains two streams, they choose one and confirm its venue and tax number before restoring. The same restore works from the command line. The recovery pack has no bucket page or storage credentials.
