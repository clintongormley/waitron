# View and reprint A4 invoices from Print Queue

A manager can open **View printout** on an A4 invoice job to see every page drawn again from the sale with the job's original or copy marking. After an A4 job has printed, **Reprint** uses the queue's existing picker to send a marked copy to any active receipt or A4 printer. Failed or uncertain jobs offer the preview. The owner said “yes” to both actions after the HP printed the invoice on 25 November (Lane I queue, A1583, and real-box handoff lines 38–40).

1. Extend the existing routes in `apps/server/src/print-api.ts` under the queue's `hardware.manage` permission. Match an A4 invoice job by ID to its A4 delivery for the same sale. For preview read the sale using `readInvoiceDocument` and the delivery's designation in the transaction. Extract the existing page drawing from `invoice-raster.ts` and render smaller PNG pages after the transaction. Return an A4 preview JSON variant with `Cache-Control: no-store`. Keep the receipt response shape. A4 receipt page rows have no actions.
2. List matched, sent A4 invoices with the `any` printer rule and both kinds of active target. Extend `print-job-reprint.ts` to check the source and printer in the same transaction that queues the copy. Use `enqueueCompletedReceiptCopy` for a receipt target and `expireInvoiceDeliveryClaims` then `reserveInvoiceDelivery` with a server-made UUID for A4. Both reach the reservation that marks Orders copies, and return the new job ID. Use `print_job.not_found` for a missing match, `print_job.not_resendable` for an unsent source, `print_job.printer_unsuitable` for an unavailable target, and `invoice_delivery.active` while a delivery is outstanding. Keep receipt rows' current target lists.
3. In `apps/dashboard/src/api/printing-api.ts`, `screens/printers-screen.ts` and the two `widgets/print-job-{preview,reprint-dialog}.ts`, reuse the preview window and picker. Show every A4 page in order with a translated description saying it was drawn again from the sale. Offer active printers with the source printer selected if eligible. Add the existing “· A4” suffix to office printers. Use A4-specific field wording for an unavailable destination. Add the wording in `i18n/strings.ts` and update both `apps/server/src/guide/{en,es}/printers.md` Print Queue sections and the A1583 line in `docs/backlog/printers.md`.

In `printers-screen.test.ts` and the widgets' sibling tests, exercise the row actions, page rendering and submitted job and printer IDs.
