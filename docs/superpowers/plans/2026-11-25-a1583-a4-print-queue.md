# View and reprint A4 invoices from Print Queue

A manager can open **View printout** on an A4 invoice job to see every page as that job was prepared, including its original or copy marking. After an A4 job has printed, **Reprint** uses the receipt queue's printer picker to send a marked copy to any active receipt or A4 printer. The owner asked for both actions after the HP printed the invoice on 25 November (Lane I queue, A1583, and real-box handoff lines 37–40).

1. In `apps/server/src/print-api.ts` and a small `print-job-a4.ts` helper, extend the existing preview and resend routes. Match the job's ID to its A4 invoice delivery and recorded sale. For preview, require `report.export` in addition to Print Queue's `hardware.manage`, as Orders does for invoice PDFs, and use the job's recorded designation with `readInvoiceDocument`. Reuse the A4 drawing in `invoice-raster.ts` to return screen-size PNG pages in an A4 preview JSON variant, with `Cache-Control: no-store`. Read the document in the transaction and draw it after the transaction ends. Keep the receipt preview response intact.
2. In the queue list, offer Reprint for a sent A4 invoice job with an active target. Offer both kinds of printer using the existing receipt-printer read and one active A4-printer read for the list. In the resend transaction, check the job is still a sent A4 invoice and require `report.view` alongside `hardware.manage` for access to historical invoices. Use `orderInvoicePrinters` and `requestPrintDelivery` from Orders with the existing receipt-copy audit callback. Add an optional duplicate-only expectation to that service so a stale request cannot send a fresh original. Return the new print job ID and use the current action's refusal when a printer has been disabled or another delivery is active.
3. In `apps/dashboard/src/api/printing-api.ts`, `dashboard-app.ts`, `screens/printers-screen.ts`, `widgets/print-job-preview.ts`, and `widgets/print-job-reprint-dialog.ts`, use the existing View printout window and printer picker. Show A4 pages in order and size them to the window. The picker needs only each destination's ID, name and active flag. Use the active original printer as its default, and include the existing “· A4” suffix. Pass the session's existing report permissions to the screen to match the server gates. Add any new labels to `i18n/strings.ts` and update both `apps/server/src/guide/{en,es}/printers.md` Print Queue sections and the A1583 line in `docs/backlog/printers.md`.
