# Customer menu styles, first slice

A manager opens **Style** on a regular menu, changes the venue's default colours and fonts, sees the published menu update in the dialog and saves the style without republishing. The save names the other menus it changes. This is the smallest editable part of [Delivery 4 and §4](../specs/2026-11-24-customer-menu-design.md#4-styles). The design's status line records the 24 November conversation. The 27 November 12:12 and 17:21 watcher notes accepted the record for earlier slices.

1. Add `customer_menu_styles` in `packages/db/src/schema/menu/customer-styles.ts` as core state with an id, name, default flag, optional media filename reference and a validated appearance value for three colours and two typeface choices. A partial unique index allows one default. Add a nullable style FK in `schema/menus.ts` in the same core rebuild. Empty means the venue default. In `packages/menu/src/customer-menu-styles.ts` and `provisioning.ts`, seed the default once from the venue's theme logo, brand colour and typeface through `readThemeInUse`. Use Waitron's regular theme values for a venue without a custom theme. Keep the cream-and-red mock as a demo style. Include the style table and menu reference in `configuration-transfer.ts` and the bundle format. An import keeps its saved default and logo. Existing Online/address omissions still apply. Declare the venue reset.
2. Add a default-style read and save beside `apps/server/src/menu-customer-preview-route.ts`, using the menu API's `menu.manage` gate and one write transaction. Return the names of other menus the save affects. Return the effective style with the existing published preview. Included menus take the outer menu's style. In `apps/dashboard/src/widgets/menu-customer-style-dialog.ts`, reuse the shared colour fields, selects, dialog and draft scope. Wire it from `menu-api.ts` and the Customer menu tab. Apply draft edits only inside the dialog. On **Save style**, show the saved result in the tab and keep other tab drafts intact.
3. In `apps/customer-menu/src/customer-menu-page{,-styles}.ts` and `main.ts`, pass the same style value to the shared page from the preview or the standalone snapshot. Derive the component palette through the existing theme functions, with the style's page, text and heading colours and separately chosen system or serif typefaces. Warn on low contrast without blocking Save. The chosen page determines the colour scheme inside the preview, independent of the dashboard theme. Use the supplied logo with the menu name as its accessible label and title fallback. The standalone build is exercised by a test fixture until Delivery 6 serves it.
4. Start red in `packages/menu/src/customer-menu-styles.test.ts` for theme seeding and saving, including export/import in `configuration-transfer.db.test.ts`. In `apps/server/src/menu-api.test.ts`, pin the permission and the effective style of a published preview. In `apps/dashboard/src/screens/menus-screen.customer-style.test.ts` and a sibling unsaved test, cover live draft paint, affected menu names, Cancel and a saved preview without republishing. Change the old palette assertions on purpose in the dashboard preview and standalone browser tests. Exercise light and dark style values and axe on the list, details, filter dialog and open language chooser, using the existing fixtures. Run the affected suites, package typechecks, core rebuild guards and built smoke. Update both Products guides, the design contract and backlog. Capture the queue's sizes, languages, themes and photo cases for the owner's approval.

Estimate 440–580 new product lines and 245–340 test lines, plus the generated baseline. If that exceeds three hours, stop after the default style is seeded, exported and visible in both previews. The needed style window and permissions then get their own agreed slice. Naming, choosing and deleting styles, editing logos, capitalisation, separator lines and extra licensed built-in font files follow in Styles. Paper and its currency rule are Delivery 5, public addresses Delivery 6, and uploaded fonts Delivery 7.
