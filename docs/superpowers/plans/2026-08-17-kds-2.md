# KDS-2 — Courses & fire control — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add courses (venue-defined) and hold-and-fire — the first course auto-fires, later courses hold (greyed) until fired from the tab (waiter) or the station (kitchen), per a venue setting.

**Architecture:** A `kitchen_courses` config table; `products.course_id` (default) + `working_order_lines.course_id` (resolved at ring time); KDS-1's `ticket_items` gains `course_id` (snapshotted) + `fired_at` (held/fired); a `fireCourse` verb + auto-fire-first in `fireLines`; a `fire_control` venue setting (`waiter`/`kitchen`) driving which UI surfaces the fire action. Non-fiscal.

**Tech Stack:** TypeScript, Drizzle + PostgreSQL (RLS), Hono, Lit + Vite, Vitest (+ browser), Testcontainers + PGlite.

**Spec:** [docs/superpowers/specs/2026-08-17-kds-2-courses-fire-control-design.md](../specs/2026-08-17-kds-2-courses-fire-control-design.md).

### Task 4: Auto-fire-first + `fireCourse` + advance-gated-on-fired

- [ ] **Step 1:** Failing test:
```ts
it("auto-fires the earliest course, holds later ones, and fireCourse releases a held course", async () => {
  const tx = pgliteTx(); const cfg = testCfg();
  const ent = await createCourse(tx, cfg, { name: "Entrantes", displayOrder: 0 });
  const pri = await createCourse(tx, cfg, { name: "Principales", displayOrder: 1 });
  const { orderId } = await fireOrderWith(tx, cfg, [line(soup, { courseId: ent.id }), line(steak, { courseId: pri.id })]);
  const items = await ticketItemsFor(tx, orderId);
  expect(byLine(items, soup).firedAt).not.toBeNull();   // earliest course auto-fired
  expect(byLine(items, steak).firedAt).toBeNull();       // later course held
  await expect(advanceTicketItem(tx, cfg, byLine(items, steak).id, "preparing"))
    .rejects.toMatchObject({ code: "ticket.item_held" });
  await fireCourse(tx, cfg, orderId, pri.id);
  expect(byLine(await ticketItemsFor(tx, orderId), steak).firedAt).not.toBeNull();
  await advanceTicketItem(tx, cfg, byLine(await ticketItemsFor(tx, orderId), steak).id, "preparing"); // now allowed
});
```
- [ ] **Step 2:** Run → FAIL → implement. In `fireLines` (KDS-1): snapshot `course_id`; set `fired_at = now()` when the item's course is already fired for the order OR is the order's earliest course (min `display_order`, null treated as earliest), else NULL. `fireCourse(orderId, courseId)` sets `fired_at = now()` on held items of that course (idempotent; `course.not_found` for unknown). Gate `advanceTicketItem` on `fired_at IS NOT NULL` → `ticket.item_held`.
