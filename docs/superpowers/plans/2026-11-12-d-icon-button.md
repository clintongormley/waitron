Drafted by a separate Sol-high invocation; shortened and checked by the Codex driver against `29f0e2cc51`. Pending Claude review and watcher clearance before build. No owner design approval claimed.

Filters, sidebar, helper consumers, ui-core, wt-button, tokens and generic variants stay unchanged.

**Contract.** `WtIconButton extends LitElement`: `label = ""`, `icon = ""`, `pressed?: boolean`, `expanded?: boolean`, `disabled = false`; reflect state properties. Undefined omits inner ARIA state; false emits `"false"`. One native `button type="button" part="button"` holds its decorative icon and hidden-from-assistive-technology tooltip repeating the localized label. Bind the tracker's four events internally. Native click bubbles once; no custom event, keyboard handler or automatic toggle. Disabled behavior and focus delegation belong to the native button; scripted presses target it.
