# A1509: cached Ubuntu packages for image smoke

**Result:** image smoke installs BlueZ and its Python libraries from the newest cached set for its exact runner image and architecture, without contacting Ubuntu on a hit. A daily main workflow refreshes the set; a cold image downloads one or fails clearly.

**Authority:** Lane I `queue.md`, A1509, owner 11 November 2026 at 16:28: “what happened to us caching these files locally?” At 16:34: “no i think we should use the local cache by default, it'll be quicker than downloading from remote services. but maybe we update our list of packages daily or something”.
