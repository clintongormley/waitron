# Customer menu styles, remaining Delivery 4

[The design, Styles and Delivery 4](../specs/2026-11-24-customer-menu-design.md#4-styles) lets a manager preview, name, share and manage styles from the Customer menu tab. The default editor and the style table, menu reference and logo reference already shipped. Use those. Each pull request works independently. Keep paper previews, currency on paper, and uploaded fonts with Deliveries 5 and 7.

## 4C. Named styles

- In `packages/menu/src/customer-menu-styles.ts`, list style IDs, names, colours, default and menus using each. Use the existing folded unique name and nullable menu reference. Empty follows the venue default. Explicit picks stay with that style after a default change. List every saved reference, including archived menus that would block deletion. Refuse deleting the default or an assigned style, naming the affected menus. Switch the default and create-and-assign a copy in one transaction each.
- In `apps/server/src/menu-customer-style-routes.ts`, use the existing menu permission and transaction for list, edit, copy, rename, make default and delete. Add `styleId: string | null` to the settings read and save through `menu-customer-online-settings-routes.ts`, `packages/menu/src/customer-menu-online-settings.ts` and the shared types in `packages/shared/src/menu-document/guest-menu.ts`. Save a selection and the rest of the tab together. Check every referenced style on write. Keep the existing appearance resolver for the outer menu and the public view's change subscription.
- Extend `apps/dashboard/src/api/menu-api.ts`, `widgets/menu-customer-style-dialog.ts`, `widgets/menu-online-save.ts`, `widgets/menu-online-preview.ts` and `screens/menus-screen.ts`. Change opens the existing labelled modal with style names, swatches, use and live phone/computer preview. Selecting a style stages the tab. Save style applies to its saved users and names the other menus it will change. Save as new style asks for a name and applies the copy to this menu at once. When it succeeds, update only the saved style selection in the tab so an unsaved address or photo choice survives. Use the existing draft scope for Escape, Cancel and switching away from edited settings.
- Start with red tests. `packages/menu/src/customer-menu-styles.test.ts` covers implicit and explicit default selection, changing default, duplicate names, create-and-assign and delete refusals. `apps/server/src/menu-api.test.ts` and `menu-api.customer-online-settings.test.ts` cover the route permission and saved selection with the other tab values. `menus-screen.customer-online.unsaved.test.ts` distinguishes staged selection, immediate copy and retained drafts. In `customer-menu-public.test.ts`, a saved style affects the published outer menu without republishing. Keep the configuration round trip in `configuration-transfer.test.ts`.
- Estimate 360–490 product lines and 170–230 test lines. The existing table and foreign keys cover these writes.
