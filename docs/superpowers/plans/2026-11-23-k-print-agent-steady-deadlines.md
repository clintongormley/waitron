# Print agent deadlines on the steady clock

A system time correction should leave a printer discovery window, typed-address check, self-enrol retry or pending network reset with the same amount of time left. The setup countdown and the deadline handed to the host's scan still use local calendar time, calculated from the time left when each is read.

The request is in [the clock backlog](../../backlog/box.md#one-steady-clock-helper-instead-of-hand-written-clock-step-back-guards). This slice covers the print agent and its network sweep. The backup schedule is a separate backlog item.
