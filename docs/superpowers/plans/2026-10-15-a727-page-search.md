# A727 Page Search Implementation Plan

> **For agentic workers:** Use `superpowers:executing-plans`, inline, task by task. The campaign already authorises this execution method; do not request another approval. Read `superpowers:test-driven-development` before writing code or tests. Planning requested native GPT6.1Sol high; never silently switch the interactive model.

**Goal:** Find existing destinations inside dashboard pages, show their localized name and containing page, and open their complete guarded address.
**Architecture:** Modules declare destinations beside their dashboard contributions. The shell combines permitted declarations with core destinations, existing `calendarViews` and visible settings tabs; existing page matches precede inner matches. Calendar windows use an independent address pair so A719 can reuse it without replacing a painter's address.
**Tech stack:** TypeScript, Lit, dashboard-kit contracts, shared text search, guarded URL state, Vitest with real Playwright Chromium.
**Spec:** [Approved scope](#approved-scope), [mockup 13](../../backlog/mockups/a718-a727-calendar-and-stations/13-periods-window.png), [mockup README](../../backlog/mockups/a718-a727-calendar-and-stations/README.md). Only the search panel is A727; the README identifies invented results.

## Approved scope

Source: owner-approved A727 in `docs/backlog/dashboard.md` at `273248bd86d119c4e2bd19dbdb36c4b0556910a8`.

**A727 (owner, 2026-10-15).** Mockup: the right-hand panel of
[the Periods window board](../../backlog/mockups/a718-a727-calendar-and-stations/13-periods-window.png) (its other results are invented). Files:
`apps/dashboard/src/nav-search.ts`, and each module's dashboard contribution.

Today page search matches a page's own name and its group heading only (`navMatches`,
`nav-search.ts`), so "Staffing" does not find the Calendar's Staffing tab. Each module lists the
tabs, windows and views inside its pages with the address that opens them — Calendar › Staffing,
Calendar › Week, Calendar › Seasons, Calendar › Periods, Prep stations › Routes and the like. A
result says where it lives ("Periods — in Calendar") and opens the page with that tab or window
showing; page names still rank first. Opening a window from an address is the mechanism A719 point 2
needs too.
