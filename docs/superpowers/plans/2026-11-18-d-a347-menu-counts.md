# Count affected menus before archiving products

A manager selecting 500 products can see how many active menus the products come off. When deleting categories, the count follows the choice about their contents and counts each menu once. Scope comes from A347's second and third bullets in `docs/backlog/menu.md` and the Lane D queue.
