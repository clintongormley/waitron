# Prefer the venue’s mail server for account email

With a saved mail server, a venue sends invitations, password resets and email-change codes through that server even if its paired test Cloud can send them. Without a saved server, the existing Cloud and practice inbox choices still apply. The ask is in `docs/backlog.md` under “A venue’s own mail server always wins” and was assigned to Lane K on 22 November 2026. This change covers those three account messages. Paid Cloud delivery and live Cloud qualification stay with their existing work.
