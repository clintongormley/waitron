# W41s-7: stop issuance and let an administrator switch identity

> **For agentic workers:** Use `superpowers:executing-plans`, inline. Before future code or tests, read the TDD skill. Each task starts with a failing behavioural assertion, observes that failure, implements the minimum, reruns, and commits with `git commit -s`. This documentation checkpoint changes no runtime behaviour.

**Goal:** Retain a definite conflict, stop new issuance on that active fiscal identity, and provide an explicit, non-destructive administrator switch using the current recovery key.

**Architecture:** The filing reply, case and conflict observation commit together. The live administrator procedure then uses the existing minute preparation and activation writer on the live database. No drain callback performs recovery, and no automatic policy helper is introduced.

**Stack:** TypeScript, Hono module routes, Lit module contributions, Vitest Node/Chromium, `useVenueDb`, SQLite transactions.
