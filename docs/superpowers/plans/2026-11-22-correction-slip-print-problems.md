# Kitchen correction slip printing problems

When a kitchen correction slip fails, staff can see **Printing problem** on its order's station card while there is work to reprint there. A later **Reprint** clears the card warning and printer alert once it prints for the same order and station on the same printer. It shows the current dishes. If the last dish leaves the station, the printer alert still shows the failed slip and the Printers screen can resend it to its own printer.
