# Kitchen correction slip printing problems

When a kitchen correction slip fails, staff can see **Printing problem** on the order's station card while there is work to reprint there. A later **Reprint** for the same order and station clears it once it prints on that same printer. If the last dish leaves the station, staff can still find the failed slip in the printer alert and resend it to its own printer.
