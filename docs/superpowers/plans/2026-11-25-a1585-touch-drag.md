# A1585: Keep touch holds on the till

**Finish line.** Hold a dish in **New order** or a course heading, wait for the outline, then drag and release where it belongs. A stationary hold still opens dish details where it already does. The menus for moving dishes or groups remain available.

**Reproduction.** On Chromium 159, the existing `touchGesture` sends trusted touch input but the default Chromium mode skipped `contextmenu` during a 1,050 ms hold. With `--enable-features=SyntheticPointerActions`, the same CDP `Input.dispatchTouchEvent` on the real New order row sent a trusted touch `contextmenu` after 652 ms. The test failed because the till left it uncancelled. The headless run still moved the dish and recorded no `pointercancel`. The owner saw the browser menu on the Pixel Tablet. The physical retest stays open under A773.
