# A1585: Keep touch holds on the till

**Finish line.** Hold a dish in **New order** or a course heading, wait for the outline, then drag and release where it belongs. A stationary hold still opens dish details where it already does. The menus for moving dishes or groups remain available.

**Reproduction.** On Chromium 159, the existing `touchGesture` sends trusted touch input but the default Chromium mode skipped `contextmenu` during a 1,050 ms hold. With `--enable-features=SyntheticPointerActions`, the same CDP `Input.dispatchTouchEvent` on the real New order row sent a trusted touch `contextmenu` after 652 ms. The test failed because the till left it uncancelled. The headless run still moved the dish and recorded no `pointercancel`. The owner saw the browser menu on the Pixel Tablet. The physical retest stays open under A773.

Hold 1,050 ms using `touchGesture` with `SyntheticPointerActions` and require a trusted touch menu, its cancellation and the drop into the course. The same Chromium build on Linux arm64 sent trusted touches but no menu, even with a 1,600 ms hold. Keep the existing native drag tests and run the cancellation tests below in the normal CI browser configuration.
- Reuse fixtures from the draft drag, sent orders, basket and last-added tests. Cover the unsent dish and course heading, the held-group heading, the sent button and held line, the basket name when details are enabled, and last-added. Send a cancelable touch `contextmenu` to each real rendered target and require cancellation. Send a touch menu to a basket field or button and a real right-click to a hold target and require both remain available. Retain the existing assertions for moving dishes and groups, opening details, and keyboard use.
- Add the canvas cancellation case to its existing suite. In the disposable browser probe, check whether a native hold selects text on the sent dish, basket name or last-added, so a CSS change earns its place.

Bind it at the hold targets in `screens/till-table-order-screen.ts`, `widgets/sent-orders.ts`, `widgets/basket.ts` and `widgets/last-added.ts`. Respect the draft row-action exclusion and the basket's existing `#pressedLine` check. Keep the draft and held heading styles. If the sent dish, enabled basket name or last-added name is selected by a hold, suppress selection only on that surface and keep its normal touch scrolling.
- Bind the helper on the editor's `.viewport` in `wt-floor-plan-canvas.ts`. It contains the canvas, table buttons and handles, and supports a hold followed by a pan. `widgets/menu-browser.ts` and `wt-floor-map.ts` already cancel context menus and use their own keyboard behavior. Keep the shared recognizer's pointer dispatch and the existing controls, timing, layout and server commands.
- Add one instruction for moving an unsent dish on a phone or tablet to **Take an order on a phone** in the English and Spanish `apps/server/src/guide/*/table-service.md` guides. Keep the tablet test open in `docs/backlog/printers.md` until the owner reports the result. Offer a picture if the owner wants to consider a separate drag handle.
