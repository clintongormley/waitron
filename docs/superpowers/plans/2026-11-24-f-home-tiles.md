# Till and dashboard tile plan

[Device home page design, piece 1](../specs/2026-11-24-device-home-page-design.md#delivery)

Staff can read a product's price or variant range and recognise a section by its folder, including on a photo. This covers shortcuts, the full menu, opened sections and search results on the till and in the dashboard Home page preview. Set-menu folders, the guest preview, search behaviour and editor settings are outside this piece.

- Start with failing tests. In `packages/shared/src/menu-document/device-home.test.ts`, check mixed availability, an unavailable parent, no orderable variants, equal variant prices and a measured unit. In `apps/till/src/widgets/menu-browser.test.ts` and `apps/dashboard/src/widgets/device-home-preview.test.ts`, pin a rendered range and the section button's accessible name with a photo. Use `EACH_UNIT_ID` for Each fixtures, including the preview fixture in `apps/dashboard/src/widgets/test-helpers.ts`. Keep genuine non-Each units in the translation and measured-unit tests. Check that an allergen filter narrows a till tile's range with the variants it removes, and move the visible Section line's contrast assertion to the remaining filtered notice. Record changed assertions in the PR.
- Add one formatter in `packages/shared/src/menu-document/device-home.ts` and export it through `packages/shared/src/index.ts`. Give it the base price, parent availability, variants with their menu price and availability, the localised unit abbreviation or an empty suffix for Each, and the locale. Reuse `formatMoney` and narrow `menuPriceRange` in `customer-menu-presentation.ts` to the price fields it reads. From the variants the surface shows, use the orderable subset when any can sell, and all when none can or the parent is unavailable. Use `min–max`, one price for an equal range, and append the measured unit once, as in `€1.60–€2.00/kg`. Variants inherit their parent's unit.
- In `apps/till/src/widgets/menu-browser.ts` use the existing offer flags, `productUnit`, `unitName` and `EACH_UNIT_ID`. In `apps/dashboard/src/screens/menus-screen.ts` pass the product list it already watches to `device-home-preview.ts`. Look up parent and variant availability by ID, treating missing flags as available, and keep prices and units from the preview document. Use the existing `unitPresentation` and the same Each ID check. In `menus-screen.home-tab.test.ts`, deliver a new product-list snapshot with the document held fixed and verify the tile range changes. No new read or wire field.
- In both tile renderers retain the existing decorative folder icon and give it a token-styled badge in a positioned photo wrapper. Use the visually hidden utility for the translated Section text and keep the till's diet-filter notice visible. Rewrite the tile paragraph in `docs/developers/design-system.md`, update the English and Spanish Products and Table service guides, and narrow the home-page work in `docs/backlog/menu.md` to the pieces still open.
- Check a Spanish measured range at phone width in `menu-browser.home-columns.test.ts`. Run the five named test files and both existing widget accessibility suites. Run the guide heading and link checks. Capture the dashboard Home page tab at 1440 and 390 px, and the real till and handheld at 1280 and 390 px. Cover English and Spanish, light and dark, Colours and Thumbnails, with and without shortcuts. Show the watcher the captures and the sold-out price rule before landing. Keep the captures outside git.

Estimate about 85 production lines, 135 test and fixture lines and 20 guide and contract lines. Lane D's local delete-menus branch also edits the dashboard preview. The queue names Lane C's tag and preview work and Lane D's later variant picker.
