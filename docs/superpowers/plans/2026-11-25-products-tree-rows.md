- **Second PR, finding products.** Give categories locale-aware A–Z `rowGroup` ranks for rendering and drag, in either sort direction. Add a `no-matches-action` slot for **Clear search and filters** to searches with or without filters. Keep All products and its count for filters alone. Reuse the action in the hidden-save notice. For save, use `shownKeys` with an option to include collapsed search matches, using the existing expanded search traversal. Map saved variants to their composite row keys. Reveal a matching new product and show the notice for a saved row that search or filters hide. Change the Product List assertions for categories staying closed with filters and document the table’s search and filter behavior in the design system. Estimate +230 production and +140 test lines.
