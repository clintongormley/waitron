# A1570 PR 1 — shared inherited fields

[Design](../specs/2026-11-24-inherited-values-design.md), Order 1 and rules 1–4, 8–9 and 11.

**Finish line.** Staff see upright text where the interface used italics. Screens can then adopt shared fields that distinguish inheriting a value from fixing it. Aim for 240–330 product lines and 220–300 test lines changed.

1. **Text and amount fields.** Give `packages/ui-core/src/components/wt-input.ts` and `wt-textarea.ts` an optional `inherited` object with `value`, caller-localised optional `suffix`, and `inTable` for a repeated column. Reuse the label and descriptions in `field-styles.ts`. Let inherited text take precedence over placeholder and hint. Keep the native placeholder as the only visible text. Use :placeholder-shown to show the small decorative arrow and reserve its space, including when a number field reports an empty value during partial input. Register the icon once in `packages/ui-core/src/components/wt-icon.ts`. An in-table field uses the native placeholder alone. Keep the value and suffix in the native control's description while empty, alongside the existing hint, error and unit descriptions. In `packages/ui/src/components/wt-price-input.ts` feed the inherited value through the price field's own placeholder formatter. For end-aligned amounts, place the icon beside an invisible width-matching copy within the amount box. Keep space for the currency and units. In existing component and accessibility suites, check the empty/explicit-same/cleared sequence, floating label, hidden arrow and description, the table case partial number input, and price layout in English and Spanish.
2. **Dropdown.** In `packages/ui/src/components/wt-combobox.ts` mark one supplied single-select option with `inherited`. Reuse `label`, `valueLabel`, the option icon and the muted option style. Recognise the empty value for this option without `showEmptyOption`. Keep the row first, with its full label, muted arrow and keyboard access even during search. On search, activate the first matching ordinary row or keep the existing add-option behavior. With neither match nor add, show No results and leave Enter idle until a person chooses a row. The closed field or link is muted with the small arrow and a caller-localised `inheritedSuffix` in its accessible description. An explicit `inTable` flag hides the closed arrow and a hidden label alone leaves it visible. In `wt-combobox.test.ts` and `.a11y.test.ts`, check both triggers, empty and explicit matching IDs, localised None, the closed arrow and suffix, and Enter after a matching and a missing search, including opening by typing.
3. **Upright text.** Remove italic declarations from `field-styles.ts`, `wt-combobox.ts`, `wt-disclosure.ts`, Dashboard's `devices-screen.ts`, `dashboard-sales-screen.ts`, `product-nutrition-picker.ts`, `product-list.ts` and `variant-table.ts`, and venue-service's `periods-list.ts`, `routing-grid.ts` and `calendar-day-box.ts`. Use muted ink for inherited allergen badges, the sales category row and inherited diet chips. Give pressed inherited chips a selector as specific as the quiet pressed chip rule. Remove the price override's forced upright style and the italic-ancestor test. Keep the current contents of closed summaries. Their `placeholder` field and remaining screen uses move together in PR 2. Start `scripts/no-italic-styles.test.ts` red on the existing longhand CSS declarations. Scan app and package `.css` and styles in production `.ts`, `.js` and `.html`; the guard checks written italic and oblique styles in both font-style and font declarations. Screen tests retain the visible distinction through assertions on content or muted ink. List changed checks in the PR.
4. **Checks and docs.** Run each changed suite green after its test-first cycle. Measure muted-text contrast in both themes in the component tests. Capture screenshots at desktop and phone width for owner review. Update `DESIGN.md`, `.impeccable/design.json`, `CLAUDE.md` and the affected field, icon, summary, Routes, Calendar and Periods wording in `docs/developers/design-system.md`, plus `docs/developers/products.md`. Correct the English and Spanish products, printers, opening hours and modifiers guides. Expect eight guide files, about twelve design-system passages and the other named references. If the budget runs out, ship the upright styles and their docs first. Narrow the A1570 backlog entry to its three remaining screen passes. Lanes D, E and H have the replacement-screen handoffs in their questions files. Screen adoption, summary contents, inherited media and the wording guard follow in their named PRs.
