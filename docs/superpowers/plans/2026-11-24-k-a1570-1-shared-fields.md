# A1570 PR 1 — shared inherited fields

[Design](../specs/2026-11-24-inherited-values-design.md), Order 1 and rules 1–4, 8–9 and 11.

**Finish line.** A screen can show the value an empty field inherits, or offer an inherit row beside the equivalent fixed choice. Existing screens keep their settings and choices. All written app styles draw previously italic text upright. Aim for 200–280 product lines and 200–270 test lines changed.

1. **Empty text and amount fields.** Add the optional `inherited` property to `packages/ui-core/src/components/wt-input.ts` and `wt-textarea.ts`. Its object carries `value`, a caller-localised optional `suffix`, and `inTable` when the control repeats down a column. Reuse the floating label, the empty control's placeholder rendering and its description wiring in `packages/ui-core/src/field-styles.ts`. Draw one small, hidden-from-assistive-technology arrow icon, registered once in `packages/ui-core/src/components/wt-icon.ts`, beside inherited text, with no arrow in a table column. Keep the amount formatting and currency placement in `packages/ui/src/components/wt-price-input.ts`. Use the inherited value while empty and its suffix in the native control's description. Keep the ordinary hint and error descriptions. In the existing component and accessibility suites, type the same value to fix it, then clear it to inherit again. Check the label floats, the arrow is absent only in the table variant, the price uses the input's locale, the description follows the state, and explicit values keep their current behaviour.
2. **Fixed choice and inherit row.** In `packages/ui/src/components/wt-combobox.ts` mark one supplied single-select option with `inherited`, reusing `label` for the localised open text and `valueLabel` for the closed text. Use the caller's empty value for inheriting, with a localised `inheritedSuffix` for the closed description. Keep that option first and visible during filtering, with its full label in the list. The matching named option still writes its own ID. Reuse the existing option, selected text, keyboard and change paths in both trigger appearances. In `wt-combobox.test.ts` and `.a11y.test.ts`, choose the explicit match and then the inherit row, use a search with no other match, and check both the value sent and what the field shows and exposes to assistive technology. Include the caller's translated None case.
3. **Upright styles and guard.** Remove the declarations from `field-styles.ts`, `wt-combobox.ts`, `wt-disclosure.ts`, Dashboard's `devices-screen.ts`, `dashboard-sales-screen.ts`, `product-nutrition-picker.ts`, `product-list.ts` and `variant-table.ts`, and venue-service's `periods-list.ts`, `routing-grid.ts` and `calendar-day-box.ts`. Preserve each surface's current color, weight, value and visibility. Use `scripts/no-italic-styles.test.ts` to refuse written `font-style: italic` or `oblique` declarations in app and package styles, including styles embedded in code. Start with the current declarations as the failing case. In the existing browser suites change only the assertions the upright rule changes, retaining the token and visibility assertions. Keep `wt-disclosure`'s existing `placeholder` field until PR 2 converts its last consumers.
4. **Verify and document.** Run each new or changed browser case red before its implementation and every changed suite green. Measure muted-text contrast against its field or row background in both themes using the component test fixtures, and inspect the shared controls in both themes at desktop and phone width. Attach screenshots for owner review before landing. Update `DESIGN.md`, the shared Forms and affected typography lines in `docs/developers/design-system.md`, and the `CLAUDE.md` rule and guard pointer. Narrow the A1570 backlog entry to the three remaining screen passes. Leave localisation, screen migrations, summary contents, inherited media and the wording guard to their named PRs. No server, settings or wire changes.
