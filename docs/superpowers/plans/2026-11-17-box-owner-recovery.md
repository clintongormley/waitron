**Exact ask** (`~/waitron-campaign-f/queue.md`, BOX-OWNER-RECOVERY-APPROVAL):
> the D608 design (waitron-cloud docs/superpowers/specs/2026-11-07-cloud-single-owner-lifecycle-design.md line 25, owner-approved choices of 9 November; built per the D631 plan lines 137–145) requires that recovering a Cloud owner's access is approved on the currently paired box by a local administrator. Build the box half against lane G's contract: the request shown to a signed-in local administrator, approve or refuse bound to account, organisation, venue and the current pairing, sent back over the existing signed Cloud exchange. Plan first, one page; no new table unless the plan shows the existing Cloud state cannot hold it.

**Finish line:** a box administrator explicitly loads requests in Cloud services, sees the exact account/email/organisation/venue and approves or permanently refuses the selected request through the current pairing. Approval records Cloud's decision; complete recovery remains unavailable until Cloud's half and joint qualification work. Reuse Cloud connection/lease state, signing/fresh-sign-in, CloudServicesScreen and wt primitives. Cloud owns pending/terminal state, expiry, replay, completion and account restrictions; add no box persistence, worker, polling, automatic retries or Cloud implementation.

**Agreed interface:** POST `/api/installations/owner-recovery-{read,approve,refuse}`, machine envelope/lease, no added `version`. Ordered `R` is `{requestId,accountId,email,organisationId,legalBusinessId,venueId,installationId,publicKey,environment,countryCode,expiresAt}`. Read signs `JSON.stringify({})` with a fresh operation UUID and returns `{requests:R[]}`. Decisions use `operationId=R.requestId`, `JSON.stringify({request:R,approvedBy})` or `{request:R,refusedBy}`; actor comes only from server `authorizedBy`. Reject extra/missing R keys, rebuild them in this order, and pin country to ES. Reply `{requestId,state:'approved'|'refused'}` must match action/ID. Cloud must adopt the new package before these actions verify there.
