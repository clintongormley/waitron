**Goal.** A table's unsent order becomes an arranged list:

- Fire now, then the table's held groups (already sent, or new). Each line is placed by its
  course's new "Held until fired" setting.
- The waiter arranges the list by ticking lines and using Move to…, or by dragging.
- **Send all** sends it as arranged; **Fire** fires just the ticked lines.
- Each bill keeps its own unsent list.
- These go: the four draft buttons, the later-addition choice, the Send to choice, the "Check before
  sending" window and the "New orders" tag.

and 13 in full; §§5–8 are A773-2's. Mock-ups: `docs/backlog/mockups/a773-courses-and-groups/01…04`

one lands, and builds on the groups this plan arranges.**

1. **Two people's drafts on one bill both join the same held group, and one sends first.** The

    const course = courseId === null ? undefined : ctx.courses.find((c) => c.id === courseId);
    if (courseId === null || course?.heldUntilFired === false) return { place: { kind: "fire" } as Place };
    const joined = ctx.held.find((g) =>

      ctx.placed.some((p) => p.courseId === courseId && p.place.kind === "join" && p.place.groupId === g.id));
    if (joined) return { place: { kind: "join", groupId: joined.id } as Place };
    const slots = [...new Set(ctx.placed.flatMap((p) => (p.place.kind === "new" ? [p.place.slot] : [])))].sort((a, b) => a - b);
    const own = slots.find((s) => ctx.placed.some((p) => p.place.kind === "new" && p.place.slot === s && p.courseId === courseId));
    if (own !== undefined) return { place: { kind: "new", slot: own } as Place };
    if (!ctx.firstOrder) {
      return ctx.held.length === 0
        ? { place: { kind: "fire" } as Place }
        : { place: { kind: "new", slot: (slots.at(-1) ?? 0) + 1 } as Place };
    }
    const order = (id: string | null) => ctx.courses.find((c) => c.id === id)?.displayOrder ?? Number.MAX_SAFE_INTEGER;
