# A798 mock-ups — degraded but trading

Pictures for [the A798 design](../../../superpowers/specs/2026-10-19-a798-degraded-trading-design.md).
Drawn in HTML with the apps' colour and spacing tokens, not screenshots. Each panel is labelled
"today — redrawn" (drawn from the code it names) or "proposed — drawn". Screens are in Spanish, as
staff see them; captions are in English. The HTML generator is kept outside the repository.
