# A798 mock-ups — degraded but trading

Pictures for [the A798 design](../../../superpowers/specs/2026-10-19-a798-degraded-trading-design.md).
Drawn in HTML with the apps' colour and spacing tokens, not screenshots. Each panel is labelled
"today — redrawn" (drawn from the code it names) or "proposed — drawn". Screens are in Spanish, as
staff see them; captions are in English. The HTML generator is kept outside the repository.

| Picture | What it shows |
| --- | --- |
| [1-full-disk-sale.png](1-full-disk-sale.png) | A counter sale when the box's disk is full: today's "No se pudo completar la venta, inténtalo de nuevo", and the proposed red strip "No se puede guardar nada" and a refusal that says not to take the money (design §2.6, §3) |
| [2-staff-notices.png](2-staff-notices.png) | The proposed strip on tills and handhelds in its three tones, with the one wording each notice uses everywhere: blue for the unsent count, amber for a printer that has stopped printing, red when nothing can be saved; "+1" when more are waiting (§4.2) |
| [3-dashboard-bell.png](3-dashboard-bell.png) | The manager's bell, with the real sidebar labels, today (only a bucket alert; the full disk is invisible) and proposed (disk and unsent-count rows pointing at the Box status page) (§4.3) |
| [4-box-status-page.png](4-box-status-page.png) | The proposed Box status page under Ajustes beside Diagnóstico: one row per part, amber for "needs attention, everything still works" and red only for "nothing can be saved", with "Reintentar ahora", an honest "Liberar 45 MB", and what really fills the disk (§4.3, §4.6) |
| [5-recovery-page-disk.png](5-recovery-page-disk.png) | A full disk at start: today the box restarts forever and a phone gets only the browser's error page; proposed, the start frees space first and, only if that is not enough, serves the recovery page with a disk-full code (§2.6, §4.7) |
| [6-wrong-clock.png](6-wrong-clock.png) | A box whose clock reads 2001: today's refusal blaming the billing data, and the proposed named refusal, keeping the card advice, with the red strip (§2.5, §4.5) |
| [7-printer-down.png](7-printer-down.png) | A kitchen printer stops: today only the table whose ticket failed is told, after two minutes; proposed, every device shows an amber strip by the same two-minute rule (§2.3; question 2) |
