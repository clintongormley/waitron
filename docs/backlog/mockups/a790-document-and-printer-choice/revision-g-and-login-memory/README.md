# A790: sole printer agreed; sharing choices between logins

G is agreed: when you open a dashboard print form without a device profile, with no usable
remembered printer and exactly one eligible printer, preselect that printer. Explain why
a previous printer is unavailable, when there was one. First use has no invented warning.
You still confirm with the named print button. G changes no open selection or submitted
request. Suggestion and selection update no memory; F requires server acceptance.

H is the sole next question, proposed only: should this browser share remembered printers
between everyone who signs in (recommended), or keep each person's choices separately?
Recommend sharing because the destination belongs to this workstation and sale venue;
the alternative preserves each person's preference. In the same browser at Harbour,
Luis earlier printed Receipt on Bar receipt; Ana later prints on Patio receipt and the
server accepts. Ana logs out and Luis signs in. Both printers remain eligible to Luis.
Shared memory opens Receipt with Patio; personal memory restores Bar. Both still require
Print a copy on the selected printer when server-designated. Signing in never prints.
Invoice and Hillside remain separate under E. G's sole-option rule cannot choose between
the two eligible printers in this H example.

Current authorization, sale venue and any device restrictions still decide what may be
shown and used. Memory grants no permissions and does not expose an inaccessible printer.
H settles login sharing only. Storage, expiry/reset, concurrent/late updates and account
transitions, device Invoice memory, portable receipt holding, multiple/zero fallback and
the complete design/plan/build remain open. Phone Equipment follows A796 Revision 4.

Eight PNG/SVG pairs cover English/Spanish, light/dark and 390/1280 px. The PNGs were rendered
in headless Chromium and visually inspected. Native SVG text boxes were checked inside
each drawing. These are static discussion drawings, with no product, accessibility,
physical-paper or legal evidence. Example-only buttons label the illustration, not a
proposed product action. Earlier boards remain history where superseded.
