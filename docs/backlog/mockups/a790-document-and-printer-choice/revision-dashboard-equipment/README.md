# A790: dashboard printers and the phone’s Equipment setting

These static drawings accompany the [latest design addendum](../../../../superpowers/specs/2026-10-19-a790-document-and-printer-choice-design.md).
A+B are approved; C is the next owner question. The complete design is not approved for build.

Each board shows four examples:

1. Dashboard Orders offers every active printer at Harbour, the sale’s venue, with Office preselected from this browser’s last use. The expanded example includes A4 and receipt paper; no profile choice is added. The illustrated alphabetical order is proposed.
2. Ana chooses Terraza for Mesa 4. It changes the phone’s single Equipment receipt-printer setting. The QR control stays visible with Equipment folded; choosing or scanning prints nothing.
3. Mesa 9 and Equipment show that same Terraza choice. A796 owns reader choices, QR/NFC behavior and NFC permission; there is no separate receipt memory.
4. **C, proposed:** after choosing Invoice, its printer selector remains inline and collapsible with the named final confirmation. A separate printer step is the alternative. One-option behavior and fallback still need agreement.
